# dazflow

A Python library and command-line tool for the workflow around a
time-series model: import, clean, explore, build candidates, select,
forecast, diagnose and report. Each step returns its numbers together with
tables, figures and findings ready for a model document.

Not yet usable: the package is being built stage by stage towards 0.1.0.
The design is in [`.agents/design.md`](.agents/design.md) and the order of
work in [`.agents/roadmap.md`](.agents/roadmap.md).
